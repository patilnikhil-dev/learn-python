open :
------
- function used to open a file in python
- if file is present then that file gets opened or else new file created
- eg. 
    1) open with w
    --------------
        name = input("What's your name? ")

        file = open("names.txt", "w") 
        # open names.txt and 
        #   i want to do write operation in it
        # NOTE: "w" opens the file and recreates the file. old content gets lost

        file.write(name) # writing name in the file(names.txt)

        file.close() # closing the file(names.txt)

        (on cmd)
            adding some names running again and again above program
            suppose we have added, Nikhil, Rahul, Akshay

        (content of names.txt)
            last value which we have added --> Akshay

    
    2) open with a
    ---------------
        name = input("What's your name? ")

        file = open("names.txt","a")
        # open names.txt
        # i want to append in that file

        file.write(name)
        # write name in file by appending with previous value

        file.close()

        (on cmd)
            adding some names running again and again above program
            suppose we have added, Nikhil, Rahul, Akshay

        (content of names.txt)
            add inputs/names get concatenated with each other (NikhilRahulAkshay)

How to read multiple words seperated by comma on single line in csv file? :
---------------------------------------------------------------------------
csv library/module :
--------------------
- eg.
    students.csv
    ------------
    Harry, "Number Four, Private Drive"
    Ron, The Burrow
    Draco,Malfoy Monor

    code_7.py
    ---------
    # In students.csv file on each line there can be more than 2 words seperated by ,
    # if we use same approach like code_6 then we get 
    #   ValueError : too many values to unpack (expected 2, got 3)
    # So for that we need to use csv library/ module to read 

    import csv

    students = []

    with open("students.csv") as file:
        # we used skipinitialspace = True to show python quotes marks in csv file
        # helpful for 1st line in csv file where multiple values/words are seperated by , and those words are enclosed in ""
        reader = csv.reader(file, skipinitialspace = True) # reads the file

        for name, home in reader:
            students.append(
                    {
                        "name": name, 
                        "home": home
                    }
                )

    for student in sorted(students, key = lambda student: student["name"]):
        print(f"{student['name']} is in {student['home']}")


How to read csv file with columns/ headers? :
---------------------------------------------
- need to use csv.DictReader
- eg.
    students_with_column.csv
    ------------------------
    name,home
    Harry,"Number Four, Private Drive"
    Ron,The Burrow
    Draco,Malfoy Monor

    code_8.py
    ---------
    # reading csv file with headers/ columns
    import csv

    students = []

    with open("students_with_column.csv") as file:
        reader = csv.DictReader(file, skipinitialspace = True) # reads the file

        for row in reader:
            students.append(
                    {
                        "name": row["name"], 
                        "home": row["home"]
                    }
                )

    for student in sorted(students, key = lambda student: student["name"]):
        print(f"{student['name']} is in {student['home']}")

inserting into csv file :
-------------------------
- need to use csv.writer
- eg.
    code_9.py
    ---------
    import csv

    name = input("What's your name? ")
    home = input("Where's your home? ")

    # newline -> added newline after each row
    with open("students_inputed_file.csv", "a", newline="") as file:
        writer = csv.writer(file)
        writer.writerow([name, home]) # ordering matters

    students_inputed_file.csv
    -------------------------
    name,home
    Nikhil,Pune
    Rahul,Pune

    Note :
    ------
    We can use DictWriter where we use column names as keys to insert values in csv file

        code snippet :
        --------------
            # using DictWriter
            writer = csv.DictWriter(file, fieldnames=["name","home"])
            writer.writerow(
                {
                    "name" : name,
                    "home" : home
                }
            )
